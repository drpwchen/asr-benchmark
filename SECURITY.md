# Security

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** (private vulnerability reporting). Please do not open a public issue for security problems.

This tool runs locally on your own audio and text. It downloads open-source models through `faster-whisper` and makes no other network calls. Anything that could make it write outside its output folder or execute content from a transcript or lexicon file is in scope.

這個工具在本機處理你的音檔與文字，除了透過 `faster-whisper` 下載開源模型外不連網。發現可能讓它寫到輸出資料夾之外、或執行逐字稿／字典內容的問題，請從 **Security** 分頁選 **Report a vulnerability** 私下通報，不要開公開 issue。
